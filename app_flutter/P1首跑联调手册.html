第 1 步 · 启动服务端

1

启动解析服务（PowerShell）

方式一（推荐，脚本自带端口清理与 Cookie 热加载）：在项目根目录执行 .\start-server.ps1。 若被执行策略拦住，先放开：Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass。

cd D:\WorkBuddyFILE\CreatorBox
.\start-server.ps1
2

方式二：手动 uvicorn

等价命令，用于排查脚本本身的问题。

cd D:\WorkBuddyFILE\CreatorBox\server
C:\Users\Administrator\.workbuddy\binaries\python\envs\default\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8080
注意：这个窗口不要关，关掉 = 服务停止。后续解析报错先回来确认它还活着。

第 2 步 · 验证服务端（不用 Flutter，先确认后端没问题）

另开一个 PowerShell 窗口。Flutter 还没编译好之前，就能把桥接链路完整验证一遍—— 这样出问题时能立刻区分是后端还是 Flutter。

1

健康检查

应返回 service: creatorbox-parser 与平台列表。

(Invoke-RestMethod http://127.0.0.1:8080/api/health).platforms -join ', '
2

解析抖音链接（验证核心联调）

把 URL 换成你手头真实的抖音/B站链接。首次解析建议 no_cache=true， 否则命中旧缓存会没有档位列表。

$body = @{ text = 'https://v.douyin.com/xxxxxxx/'; no_cache = $true } | ConvertTo-Json
$r = Invoke-RestMethod -Uri http://127.0.0.1:8080/api/parse -Method Post `
  -ContentType 'application/json' -Body $body
"平台: $($r.platform) | 标题: $($r.title) | 档位数: $($r.options_count)"
$r.options | Select-Object gear, url | Format-List
3

桥接出码（模拟 App 端）

拿到的 6 位码即为 App 端要显示的码。注意：同一 provider_uid 再次出码会作废旧码。

$uid = 'dev-uid-001'
$b = @{ provider = 'app_device'; provider_uid = $uid } | ConvertTo-Json
$code = (Invoke-RestMethod -Uri http://127.0.0.1:8080/api/auth/bridge/create `
  -Method Post -ContentType 'application/json' -Body $b).code
"绑定码 = $code  （去小程序 会员 → 跨端绑定 输入它）"
4

确认绑定后取 token（小程序确认后执行）

未绑定时返回 400 not_bound，这是正常的，不是错误。

$p = @{ provider = 'app_device'; provider_uid = $uid } | ConvertTo-Json
$res = Invoke-RestMethod -Uri http://127.0.0.1:8080/api/auth/bridge/poll `
  -Method Post -ContentType 'application/json' -Body $p
"token = $($res.token)"
"会员 = $($res.member.is_member)"
Invoke-RestMethod -Uri http://127.0.0.1:8080/api/auth/me -Headers @{ 'X-User-Token' = $res.token } | ConvertTo-Json
为什么编译必须你来：沙箱内任何需要 spawn 子进程的命令都会崩 （CreateFile failed 231：管道范例全占用）， flutter、dart analyze 都在其列。 我实测过三条绕行路线均不可用（analysis server 协议不匹配、analyzer 包缺内部依赖、 dartdevc 无法解析 package），不再为此消耗你的时间。

第 3 步 · Flutter 首跑

1

生成平台壳

lib/ 与 pubspec.yaml 已写好， flutter create 只补 windows/、android/ 脚手架， 不会覆盖你的业务代码。

cd D:\WorkBuddyFILE\CreatorBox\app_flutter
flutter create . --org cn.iyama --project-name creatorbox_app
2

拉依赖

依赖：http、shared_preferences、uuid，均为纯 Dart/官方插件，无需额外原生配置。

flutter pub get
2.5

跑静态检查（强烈建议）

项目内已备好 tools/cb_check.sh，走 dartdevc 真编译， 不需要 flutter 命令，可在 Git Bash / PowerShell 里跑。 它比肉眼看代码可靠——能把类型错误、未定义符号直接列出来。

bash tools/cb_check.sh
它诚实设计：若 flutter pub get 没跑过（依赖未解析）， 它会报「⛔ 无法给出可信结论」并退出码 2，而不是谎报「检查通过」。 所以你看到 ✅ 通过 = 依赖已解析 + 真无错误，可放心依赖这个结论。
它已帮我抓到 1 处：session.dart 里的 const Uuid().v4() 已改为 Uuid().v4()。 const 在此处零收益，却可能在 uuid 版本差异下变成编译错误。
3

跑 Windows 桌面端

若提示缺少 Visual Studio C++ 工具链，装 Visual Studio 2022 的 使用 C++ 的桌面开发 工作负载即可（只需这一项，不必装全套）。

flutter run -d windows
4

跑 Android（可选，先确认 Windows 通）

真机调试时 127.0.0.1 指向手机自己，必须换成本机局域网 IP。 先查 IP：ipconfig 找「IPv4 地址」。

flutter devices
flutter run -d <设备ID> --dart-define=CB_API_BASE=http://192.168.x.x:8080
Android 额外注意：明文 HTTP 在 Android 9+ 默认被禁。联调期需要在 android/app/src/main/AndroidManifest.xml 的 <application> 上加 android:usesCleartextTraffic="true"。 正式上架前换成 HTTPS 并移除该属性。

第 4 步 · 桥接登录全流程走查

步骤操作预期
1启动 App（Windows）停在桥接登录页，显示 6 位码 + 倒计时
2小程序 → 会员 → 跨端绑定 → 输入码提示「绑定成功」
3观察 App（3 秒内）自动跳首页，右上角显示用户与会员标识
4关掉 App 再开直接进首页（token 已持久化，90 天有效）
5右上角 ⋮ → 退出登录 / 换账号弹确认框 → 确认后退回桥接登录页，可绑新账号
验收标准：第 3 步必须自动跳转，不需手动操作。若停在原地， 回头看 App 窗口是否已显示「轮询失败」红字——那说明服务端中途断了。
第 5 步是本轮新增的闭环出口，务必验证——此前 logout 是死代码，登录后根本退不出来。

第 5 步 · 解析核心联调

实测基线（沙箱已跑通，你对照验收即可）：
  • 抖音 v.douyin.com/ntaaK4aH9pE/ → 0.9s，6 档，BGM 有，字幕无
  • B站 BV1GJ411x7h7 → 0.6s，仅 1 档 720P（wbi 签名门槛，v4 §3.2 已登记为 P2 专项，非本次回归）
  • 抖音档位排序后的预期显示：1080P（play-api 通道）→ 720P·875kbps → 720P·636kbps → 720P·537kbps → 540P·640kbps → 540P·346kbps
  • 粘贴抖音链接 → 结果页应出现 6 档 + BGM 卡；第一档是 1080P
  • 粘贴B站链接 → 只有 1 档 720P，页面会显示说明文字（已内置，非 bug）
  • 点头部「复制主档直链」 → 拿到最清晰那条；点各档卡片 → 复制该档直链
  • 勾选「强制重新解析」再解析同一条 → 档位必定出现（这是验证缓存瘦手的正确姿势）
  • 点「从剪贴板读取并解析」→ 先在浏览器复制一条链接，点按钮应直接进结果页
  • 停掉 server 后回首页 → 平台数变红字「解析服务未连接」
关于 YouTube：解析信息能拿到，但直链绑定服务端出口 IP， 本机打开可能 403。这是 v4 §2.3 已知的 IP 锁，由 P2 本机引擎根治，P1 不修，属预期行为。
抖音没有字幕是正常的——字幕提取目前只有 YouTube（ytdlp 管线）有， 抖音/B站要等 v4 §3.2 的字幕 spike。结果页字幕卡只在有内容时出现，不会空占位。
