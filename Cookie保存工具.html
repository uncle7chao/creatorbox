Cookie 一键保存工具

登录只是第一步 —— 还要把浏览器的 Cookie 交给解析服务。本页帮你两分钟完成。
📕 小红书 Cookie
🌐 微博 Cookie
1确认已登录：浏览器打开 xiaohongshu.com 右上角能看到自己的头像
2按 F12 → 顶部切到 Network（网络）→ 按 F5 刷新页面
3在请求列表点第一个（名字是 explore 或 xiaohongshu.com）→ 右侧找到 Request Headers 里的 Cookie: 行
4把「Cookie:」后面的整串内容全选复制（很长，几百到几千字符），粘贴到下面输入框
✅ 文件已下载 —— 接着看下面的「最后一步」
1确认已登录：浏览器打开 weibo.com 能看到首页
2按 F12 → Network → F5 刷新
3点第一个请求（weibo.com）→ Request Headers → Cookie: 行
4复制「Cookie:」后面的整串，粘贴到下面
✅ 文件已下载 —— 接着看下面的「最后一步」
⚠️ Cookie 等同你的登录身份，不要发给任何人（包括我）。
最后一步（两个文件都下载后）：
把下载好的 xhs-cookie.txt / weibo-cookie.txt 移动到这个文件夹：

D:\WorkBuddyFILE\CreatorBox\server

然后重新运行 start-server.ps1，启动时会显示 「小红书 Cookie: 已加载」「微博 Cookie: 已加载」。
到小程序里再解析小红书分享链接 / 打开微博榜单，就都通了。
