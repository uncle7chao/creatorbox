# CreatorBox 云资源选型：国内 vs 香港，成本重算

> 版本 v1.0 ｜ 2026-10-04 ｜ 承接《商业模式设计》
> 触发问题："买国内服务器是不是不限带宽？"

---

## 0. 直接回答

**不是不限带宽。而且"不限带宽"这个认知会让你做出更贵的决策。**

但结论是好的：**换成国内 CDN，把上一版"免费用户净亏"的判断彻底翻过来了。**

---

## 1. 概念纠正：带宽 ≠ 流量

这是云厂商最容易让人误解的地方，也是很多人买错的原因。

| | 带宽（Bandwidth） | 流量（Traffic） |
|---|---|---|
| 是什么 | 水管**粗细**（Mbps） | 流过的**水量**（GB） |
| 计费 | **限速**，按 Mbps 买，按月付 | **按量**，按 GB 买 |
| 花钱逻辑 | 贵在**速率**，全天不开也照付 | 贵在**用量**，用多少付多少 |
| 典型产品 | CVM / 轻量应用服务器 | CDN / 对象存储 COS |

**没有任何云厂商提供"不限流量的固定带宽"** —— 因为不限流量的成本无法预估。

⚠️ **"阿里云 2核2G 200M 带宽 68元/年"这类促销看着像不限带宽** —— 那是**峰值 200M**（单台最多 200Mbps，共享出口池），且通常**带月流量上限**（如 500GB / 800GB），超出后要么限速要么另计费。**它不是不限流量。**

## 2. 2026 年真实刊例价

### 2.1 固定带宽（CVM / 轻量）—— 按 Mbps 买

| 云厂商 | 1–5 Mbps | 5–10 Mbps | 10 Mbps 以上 | 备注 |
|---|---|---|---|---|
| 腾讯云 | ~¥20/Mbps/月 | — | **~¥70/Mbps/月** | 10M 以上跳档很陡 |
| 阿里云 | **~¥23/Mbps/月** | — | **~¥80/Mbps/月** | 国内节点最广 |

**要 100 Mbps 跑视频？腾讯云约 ¥7000/月，阿里云约 ¥8000/月。** 这比 CDN 贵 15 倍以上。

### 2.2 CDN 流量 —— 按 GB 买 ⭐ 推荐

| 流量阶梯 | 腾讯云（中国大陆） | 阿里云（大陆起） |
|---|---|---|
| 0–2 TB | **¥0.21/GB** | ~¥0.24/GB |
| 2–10 TB | ¥0.20/GB | ~¥0.22/GB |
| 10–50 TB | ¥0.18/GB | ~¥0.20/GB |
| 50–100 TB | ¥0.15/GB | — |
| ≥100 TB | ¥0.11/GB（可谈） | 可谈 |

CDN 也支持**按带宽计费**（阶梯到达）：0–500Mbps 为 **¥0.53–0.585/Mbps/天**。⚠️ 按带宽计费适合平稳业务，**波动大的下载场景应该选按流量**。

> 以上均为**刊例价**。腾讯云月消费超 10 万可商务洽谈月结与更优价格（需在官网自助入口申请）。

## 3. 成本重算：免费用户的单人月经济性

**修正上一版的判断。** 场景：DAU 3000，人均 2 次广告/天，eCPM 60，每人每天下载 2 次（60 次/月），视频 25MB。

| 项 | 香港服务器 | **国内 CDN** |
|---|---|---|
| 广告收入 | +¥1.8 | +¥1.8 |
| 月流量 | 1.46 GB | 1.46 GB |
| 带宽单价 | ¥2.0/GB | **¥0.21/GB** |
| 带宽成本 | **−¥2.93** 🔴 | **−¥0.31** ✅ |
| **免费用户净额** | **−¥1.13** | **+¥1.49** ✅ |

> ⭐ **决定成败的不是"免费策略"，是"带宽单价"。** 同一个免费策略，换个部署位置就从亏变赚。
> 这也验证了上一版的判断方向：真正的死穴在带宽，不在商业模式。

### 3.1 三档日活的月成本对比（人均 60 次下载/月）

| 日活 | 月流量 | 香港中转 | 国内 CDN | 广告收入 | **国内 CDN 净利** |
|---|---|---|---|---|---|
| 1,000 | 1.5 TB | ¥3,000 | **¥315** | ¥1,800 | **+¥1,225** |
| 3,000 | 4.5 TB | ¥9,000 | **¥900** | ¥5,400 | **+¥4,240** |
| 10,000 | 15 TB | ¥30,000 | **¥2,800** | ¥18,000 | **+¥14,940** |

**加上 9.9 订阅后净利更高**（3000 日活 + 6% 转化 ≈ +¥1,680）。

> ⚠️ 前提仍是"直连优先"：**如果全部走自己服务器中转，即便用国内 CDN，3 万流量也只有 ¥6,300 广告收入对 ¥9,000 成本，还是亏。**
> **必须让在线预览走平台 CDN 直连，只对"保存到相册"做中转。**

## 4. 推荐架构：三个机房，各司其职

```
┌─ 国内（腾讯云 / 阿里云，任意一家）──────────────┐
│  ✅ API 服务 / 小程序后端 / 管理后台             │
│  ✅ 解析服务（访问国内平台反而更快、更不容易被封） │
│  ✅ CDN 视频中转（¥0.21/GB）                    │
│  ⚠️ 需 ICP 备案 + 域名备案                       │
└────────────────────────────────────────────────┘
┌─ 平台 CDN 直连（不经过我们）─────────────────┐
│  ✅ 在线预览播放（video 组件指向平台地址，零成本） │
│  ✅ 视频域名校验比图片宽松，无需 downloadFile 白名单 │
└────────────────────────────────────────────────┘
┌─ 香港 43.159.141.17（保留）───────────────────┐
│  ✅ 需要境外 IP 的场景 / 未来多平台扩展          │
│  ❌ 不做视频中转（¥2.0/GB 太贵）                │
└────────────────────────────────────────────────┘
```

### 4.1 为什么建议"买国内"而不是继续用香港

| 维度 | 香港 | 国内 |
|---|---|---|
| 视频中转成本 | ¥2.0/GB 🔴 | **¥0.21/GB** ✅ |
| 访问抖音/小红书 | 需要跨境，可能被限流 | **同网，稳** |
| 服务器成本 | 2C2G 较贵 | 轻量 ¥15.7/月起 |
| 带宽单价 | 高 | 低 |
| 需要备案 | 不需要 | ⚠️ **需要** |
| 内容安全审核 | 需另接 | 需另接（与位置无关） |

> ⭐ 意外收获：**解析服务放国内，访问抖音/小红书反而更快、更不容易触发 IP 风控。** 之前担心"解析要放海外防封"其实不必要 —— 那些平台的数据中心本来就在国内。

## 5. ⚠️ 备案事项（这是国内方案的唯一硬门槛）

| 事项 | 要求 | 周期 |
|---|---|---|
| **ICP 备案** | 服务器在中国大陆，域名必须备案 | **15–20 工作日** |
| **域名证书** | SSL HTTPS 证书 | 数小时～1 天 |
| **小程序备案** | 2023 年起小程序本身也需备案 | 1–3 周，**与 ICP 备案并行推进** |
| **CDN 域名** | 需在后台配置 | — |

### 5.1 排期影响

⚠️ **ICP 备案 15–20 个工作日是长周期项，会阻塞小程序上线。**

**建议：今天就启动备案。** 备案期间可以用香港机做开发联调，等备案通过再切国内正式环境。

## 6. 采购清单与预算

### 6.1 起步配置（0–1000 日活，验证期）

| 项 | 选型 | 年/月成本 |
|---|---|---|
| API 服务 | 轻量 2核4G / 5M / 500GB流量 | **¥188/年** |
| 视频中转 | CDN 按流量（初期量小，0–100GB） | **¥0–21/月** |
| 域名 + SSL | `.com` + 免费 DV 证书 | ¥70–90/年 |
| 对象存储 | COS 轻量（素材库） | ¥0–20/月 |
| **合计** | | **≈ ¥300–400 / 年** |

> 🎉 **起步成本极低。** 一年三百多块就能跑通全链路。

### 6.2 增长期（1万–3万日活）

| 项 | 选型 | 月成本 |
|---|---|---|
| API 服务 | 4核8G / 8M | ¥150–300 |
| 视频中转 | CDN 按流量（15–50 TB 阶梯） | ¥2,800–10,000 |
| 对象存储 + 流量 | COS | ¥200–600 |
| **合计** | | **≈ ¥3,000–11,000 / 月** |

⚠️ 视频中转会随规模线性增长，**但增速慢于广告收入**（因为用户下载量增长通常慢于 DAU 增长，且免费额度限制了人均下载次数）。这个"剪刀差"是模式成立的关键。

## 7. 三个必须做的成本控制

| 措施 | 效果 | 优先级 |
|---|---|---|
| **在线预览走平台 CDN 直连** | 省掉 70–85% 的视频流量 | 🔴 P0 |
| **解析默认返 720p 而非原分辨率** | 再省 50–70% | 🔴 P0 |
| 免费额度硬上限（3 次/月） | 限制人均下载量 | 🔴 P0 |

## 附：常用公式

```
月流量(GB)      = DAU × 30 × 人均下载/天 × (视频MB ÷ 1024)
月CDN成本       = 月流量 × 单价元/GB      （阶梯累进，注意跨档）
月广告收入      = DAU × 30 × 人均展示/天 × eCPM ÷ 1000 × 50%
月订阅收入      = DAU × 转化率 × 9.9 × 0.994
月净利          = 广告 + 订阅 − CDN − 服务器 − 存储
```
