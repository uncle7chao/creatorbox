# 小程序 UI 设计规范

> 基于 v3 定位定稿 | 2026-10-05
> **与之前那三张稿的差异**：主CTA 和文案按 v3 定位重做（不再是"素材采集/AI 净化"）

---

## 零、v3 定位对 UI 的直接约束

| v3 结论 | UI 必须体现 |
|---|---|
| 定位是"韧性"不是"功能多" | 首页**不列功能清单**，只强调"10 个平台都验证过" |
| 解析**不限次** | 首页额度区第一个指标是"不限"，不是"3次" |
| 会员核心是**批量解析** | 会员页权益排序：批量第一，画质第二 |
| 免费能拿到**干净原片** | 不宣传"去水印质量"，只宣传"无水印" |
| 平台改版是主要风险 | 「全部已验证」+ 健康度徽章 |

## 一、三屏核心结构

### 屏 1 · 解析首页（转化率最高）

```
深色区（#173404）
├── 标题「素材解析」+ 右上「9.9 开通会员」
├── 主文案「去掉水印 / 只要干净素材」  ← 20px，转化核心
└── 副文案「抖音 · B站 · 小红书 · 10 个平台」

悬浮白卡（-2.25rem 上提）
├── textarea：粘贴视频链接（3 行，不压太矮）
├── [开始解析]（实心主按钮，占满）
└── [粘贴]（次要按钮，读剪贴板）

额度三指标（常驻可见）
├── 不限 ·  解析次数    ← ⭐ 强调不限
├── 2/2  ·  今日保存    ← 成本闸门
└── 720P ·  免费画质    ← 引导付费的钩子

琥珀提示条：今日保存已用完 · 解析不限次数，继续使用
平台标签区：抖音 B站 好看视频 西瓜 微博 +5
  └── 右侧「全部已验证」← v3 韧性定位的可视化
```

**设计硬约束**：
| 决策 | 原因 |
|---|---|
| 深色区+ 悬浮白卡 | 让"粘贴链接"成为唯一视觉焦点 |
| 三个额度指标常驻 | 免费额度是**成本闸门**，用户必须随时看到 |
| 「不限」字号最大 | 免费策略的差异点（竞品通常限次） |
| 「全部已验证」徽章 | 把"改版预警"转成信任背书 |
| 底部免责灰字 11px | 规范 3.13 硬要求，但不显眼（显眼会伤转化） |

### 屏 2 · 结果页（三个变现触点）

```
顶部信息栏
├── 标题（超长省略）+ 作者 · 时长
└── 绿色徽章「无水印」← 兑现承诺的信任点

视频预览区（16:9）

清晰度选择
├── 540P（可选）
├── 720P（实心深绿 = 当前）
└── 1080P（虚线琥珀 = 引导付费）
    右上小字「免登录上限 720P」← 诚实告知

两个虚线按钮（可选感）
├── 看广告解锁 1080P    ← 触点①
└── 看广告再存 1 次      ← 触点②

[保存到相册]  ← 实心主按钮，唯一强制动作
Banner 广告位
免责灰字 11px
```

**设计硬约束**：
| 决策 | 原因 |
|---|---|
| 720P 实心、1080P 虚线 | **实线=强制，虚线=可选**。不虚线化会让用户觉得被强迫 |
| 1080P 用琥珀色不用灰| 免费拿不到的高亮，才是"差一点点"的心理钩子 |
| 「免登录上限 720P」 | 诚实告知，避免用户以为我们技术不行 |
| 两个虚线按钮并排 | 视觉权重相同 = 用户自由选，不替他们做决定 |
| 结果页只有 Banner，**无插屏无开屏** | 插屏会打断「保存」这个动作 |
| 保存按钮放在广告位**上方** | 先满足需求，再要求看广告 |

### 屏 3 · 会员页（决定 9.9 卖不卖得动）

```
深色头（#412402）
├── 「创作者会员」
├── 9.9 元 / 月（30px）
└── 「一次付费，批量处理整条素材」← 直接说清价值

免费区（灰色区隔）
└── 6 项：解析不限 / 视频每日2次 / 图集每月3次 / 批量每日1条 / 720P / 有广告

会员区（绿色高亮卡片）
└── 5 项：视频不限 / 图集不限 / 批量不限 / 1080P / 全免+永久

琥珀说服条：「做自媒体一次要处理几十条，免费额度根本不够用」

[开通会员]  +  「可随时取消 · 不自动续费」
```

**设计硬约束**：
| 决策 | 原因 |
|---|---|
| 免费区在**上**，会员区在下 | 先给用户"我够用吗"的判断依据 |
| 会员区用绿色卡片包围 | 视觉上"这块是解开的" |
| **批量解析排在会员权益第3位但加"不限条数"** | 它是核心卖点，但要放在对比里才显得有价值 |
| 不写划线价 ¥19.9 | 从来没有19.9 这个价，写了是虚假原价被投诉 |
| 「不自动续费」 | 9.9 无年费的必要说明，降低决策门槛 |

## 二、变现触点清单（全部用户主动触发）

| # | 触点 | 位置 | 目的 |
|---|---|---|---|
| ① | 看广告解锁 1080P | 结果页清晰度区下方 | eCPM 最高（50–120元） |
| ② | 看广告再存 1 次 | 结果页保存区上方 | 提升免费用户留存 |
| ③ | 解析失败看广告重试 | 失败弹窗 | 不让用户流失 |

⚠️ **规范 5.1 只管"分享诱导"，用户主动触发激励视频是合规的。**
但**绝不能**做成"分享后解锁功能"。

## 三、待你确认的视觉决策

1. **主色**：现在用深绿（#173404）。要不要换成跟你 GEO Optimizer 的橙金调性统一？
2. **iOS 端**：小程序无此限制（原生支持存相册），无需额外设计
3. **图集结果页**还没出 —— 图集是多图网格 + 逐张保存还是打包 zip？（打包要服务器 CPU，成本另算）

### 免费额度最终值（待定）
| 项 | 当前设计 | 依据 |
|---|---|---|
| 解析 | 不限 | 成本只是几个 HTTP 请求 |
| 视频保存 | 每日 2 次 | 唯一带宽成本项 |
| 图集保存 | 每月 3 次 | 图集单张 0.46MB，成本低 |

⚠️ 这三个数字直接决定盈亏平衡转化率，**建议上线后看埋点数据再调**。

## 四、视觉密度规范（2026-10-07 竞品拆解后新增，强制）

> 来源：第一版高保真稿被用户批评「简陋」。线框级 ≠ 成品级。
> 以下 8 条是渲染任何 UI 稿时的**最低视觉标准**，对标竞品成品（轻抖/全家桶）：

| # | 规则 | 竞品出处 |
|---|---|---|
| 1 | 页头用**多层渐变叠加**（radial 高光 + linear 主色），不用单一线性渐变 | 全家桶首页 |
| 2 | 每个功能入口一个**彩色渐变圆角图标**（渐变底 + 白色图形 + 同色系投影）| 轻抖8宫格、全家桶图标行 |
| 3 | 深色区内的指标用**毛玻璃胶囊**（半透明白 + blur），不放白卡灰字 | 竞品会员页 |
| 4 | 关键数字用**渐变文字**（background-clip: text）| 全家桶价格区 |
| 5 | 排行/榜单用**奖牌徽章（金银铜渐变）+ 热度条**，不用纯文字排名 | 全家桶漫剧播放量 |
| 6 | 主按钮**同色投影**（box-shadow 品牌色系）+ 箭头/图标指示 | 竞品所有 CTA |
| 7 | 新功能加 **NEW/内测 角标**（红底白字小方块）| 全家桶、工具箱 |
| 8 | 卡片阴影用**品牌色系**（深棕 rgba(61,32,0,.x)），不用纯黑 | 整体协调 |
