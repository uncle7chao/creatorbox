## 2. ⭐ 踩到并修复的关键坑

### 坑：我把 `dy-water` 理解反了

抖音图集有两个 URL 字段，**模板标记语义相反**：

| 字段 | 模板标记 | 含义 | 用它？ |
|---|---|---|---|
| `url_list` | `~tplv-dy-aweme-images` | **原始无水印图** | ✅ |
| `download_url_list` | `~tplv-dy-water-v2` | **带账号水印的下载版** | ❌ |

⚠️ **我最初看到 `water` 就以为是 "watermark removed"（去水印），实际是 "watermark 加上"。** 结果选中了带水印的那一组。

**教训：字段名和标记不能靠字面猜，必须下载后肉眼验证。**

### 附带解决：WebP 格式问题

小程序 `wx.saveImageToPhotosAlbum` **不支持 WebP**。

`url_list` 三个地址里：
- `[0]` `.webp`
- `[1]` `.webp`
- `[2]` **`.jpeg`** ← 取这个

⚠️ 改 URL 查询参数（`?format=jpeg`）会 **403**，签名校验失败。**格式必须从候选地址里挑，不能改 URL。**

## 3. 最终实现（已落代码）

```python
# ⭐ 图集：取 url_list（模板 ~tplv-dy-aweme-images = 原始无水印图）
# ⚠️ 不要用 download_url_list —— 它是 ~tplv-dy-water-v2，底部带「抖音号」水印
# url_list 第 3 个是 .jpeg，前两个是 .webp（小程序不支持 webp）
cands = list(im.get('url_list') or [])
jpeg = next((u for u in cands if '.jpeg' in u or '.jpg' in u), None)
fallback = next((u for u in cands if '.webp' not in u), None)
```
