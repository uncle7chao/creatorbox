## 0. 结论

| 方案 | 结果 | 说明 |
|---|---|---|
| **Playwright + 本机 Chrome** | ✅ **成功** | 首次 3.67s，后续 ~3s，20 档无水印 |
| 真实 Chrome + CDP（fetch_in_page） | ✅ 成功 | 同样有效 |
| curl_cffi 指纹伪装 | ❌ 失败 | 首页只给 `__ac_nonce` |
| 纯 Python + CookieJar | ❌ 失败 | 同上 |
| 纯 Python + 真实 cookie + a_bogus | ❌ 失败 | 空 body |

### 🔑 根因

**抖音对首页做了 JS 执行级检测，只有真实浏览器能通过。**

不是 cookie 问题（喂真实 cookie 也不行），不是签名问题（传了 `a_bogus` 也不行）—— 是 **TLS 指纹 + JS 计算的隐藏参数**。

## 1. ⭐ 去水印的真实机制（重要更正）

我之前说"把 `playwm` 替换成 `play`" —— **这个说法是错的**。

实测 `download_addr` 也**不含** `playwm`：

| 字段 | URL 特征 | 是否无水印 |
|---|---|---|
| `video.download_addr` | `/tos/cn/...` | ❌ 带水印 |
| **`video.bit_rate[].play_addr`** | `/tos/cn/...` | ✅ **纯净** |
| `video.play_addr` | `/tos/cn/...` | 🟡 仅 540p 一档 |

⚠️ **URL 路径无法区分水印，必须按字段名区分。**

**正确做法：取 `bit_rate` 数组，按 `gear_name` 选清晰度。**

实测档位：`normal_1080_0` / `normal_720_0` / `normal_540_0` 等共 20 档。

## 3. 技术实现

### 3.1 依赖

```bash
pip install playwright
# 不需要下载 Chromium，用 channel="chrome" 复用本机 Chrome
```

### 3.2 核心代码

`douyin_parser.py` —— 常驻浏览器解析器

```python
browser = await pw.chromium.launch(
    channel='chrome',        # 复用本机 Chrome，零下载
    headless=True,
    args=['--disable-blink-features=AutomationControlled'],
)
```

**关键设计：**

| 设计 | 说明 |
|---|---|
| **常驻浏览器** | 启动一次，后续解析复用会话（省 10s 初始化） |
| **`page.evaluate(fetch)`** | 在页面上下文里发请求，**自动带全部 cookie 与指纹** |
| **`add_init_script`** | 抹掉 `navigator.webdriver` 反自动化标记 |
| **`asyncio.Lock`** | 同一浏览器串行，避免并发崩页面 |
| **健康检查** | 监控 cookie 是否失效（平台改版预警） |

### 3.3 解析流程

```
分享口令
  → 正则提取短链
  → page.goto 短链（浏览器跳转，带真实指纹）
  → 从 page.url 提取 aweme_id
  → page.evaluate(fetch 详情接口)   ← 关键
  → 取 bit_rate[] 选清晰度
  → 返回无水印地址
```

## 4. 工程约束

| 项 | 数据 | 影响 |
|---|---|---|
| **内存** | 单浏览器实例 500MB–1GB | 需 4C8G 服务器 |
