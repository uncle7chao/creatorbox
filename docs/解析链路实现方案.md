
## 1. 第一步：提取短链

### 输入形态

抖音分享出来的是**一段文本**，不是纯 URL：

```
7.68 复制打开抖音，看看【旅行笔记的作品】城市漫游第3集 https://v.douyin.com/iRxxxxx/ 复制此链接，打开Dou音搜索，直接观看视频！
```

### 实现

```python
import re

URL_RE = re.compile(r'https?://[^\s，。、""\'）)】\]]+')

def extract_url(text: str) -> str | None:
    """从任意分享文案中提取第一个 http(s) 链接"""
    m = URL_RE.search(text or '')
    return m.group(0) if m else None
```

### 关键点

| 项 | 说明 |
|---|---|
| 正则要覆盖 | `https?://` + **排除中英文标点和括号** |
| 短链域名 | `v.douyin.com` / `iesdouyin.com` |
| 兜底 | 用户可能只贴了纯 URL（无文案），正则同样命中 |

> ⚠️ **不要用 `\S+`** —— 会把末尾的中文标点一起吞进来。

## 2. 第二步：跟随 302 拿真实地址

短链 `v.douyin.com/xxx/` 会 302 跳到 `www.iesdouyin.com/share/video/{id}/...`

### 实现

```python
import httpx

UA_MOBILE = ("Mozilla/5.0 (iPhone; CPU iPhone OS 17_0 like Mac OS X) "
             "AppleWebKit/605.1.15 (KHTML, like Gecko) Version/17.0 Mobile/15E148 Safari/604.1")

async def resolve_short_url(url: str) -> str:
    """跟随跳转，返回最终地址。只读响应头，不下载正文。"""
    async with httpx.AsyncClient(follow_redirects=False, timeout=10) as c:
        r = await c.get(url, headers={'User-Agent': UA_MOBILE})
        if r.status_code in (301, 302, 307, 308):
            return r.headers.get('Location', '')
        return url
```

### 关键点

| 项 | 说明 |
|---|---|
| `follow_redirects` | **设 False**，手动读 Location，避免跳到最终页浪费带宽 |
| **必须用移动端 UA** | PC 端 `www.douyin.com` 已是 CSR 空壳（72KB 无数据），移动端才有 SSR |
| 禁止 | 跟随到最终页面后整页抓取 —— 只看 Location |

## 3. 第三步：提取内容 ID

### 两种内容

| 类型 | ID 位置 | 特征 |
|---|---|---|
| **视频** | `/share/video/{id}/` | 单个 aweme_id |
| **图集** | `/share/note/{id}/` 或 slides | images 数组 |

### 实现

```python
import re, urllib.parse as urlparse

RE_VIDEO = re.compile(r'/video/(\d{6,})')
RE_NOTE  = re.compile(r'/(?:note|slides)/(\d{6,})')

def extract_aweme_id(url: str) -> tuple[str | None, str | None]:
    """返回 (aweme_id, content_type)"""
    for pat, ctype in ((RE_VIDEO, 'video'), (RE_NOTE, 'image')):
        m = pat.search(url)
        if m:
            return m.group(1), ctype
    return None, None
```

> ⚠️ 小红书的 ID 不是纯数字，需要另一套规则（见 §8）。

### 三级：移动端 SSR 花括号栈解析（兜底）

抖音把数据注入 `window._ROUTER_DATA`，需要**花括号深度栈**提取 JSON。

```python
import json, re

ROUTER_KEY = 'window._ROUTER_DATA'

async def parse_level3(aweme_id: str) -> dict | None:
    url = f"https://www.iesdouyin.com/share/video/{aweme_id}/"
    async with httpx.AsyncClient(timeout=15) as c:
        r = await c.get(url, headers={'User-Agent': UA_MOBILE})
        if r.status_code != 200:
            return None
        html = r.text

    i = html.find(ROUTER_KEY)
    if i < 0:
        return None
    j = html.find('{', i)
    if j < 0:
        return None

    # 花括号深度栈提取
    depth, in_str, esc = 0, False, False
    for k in range(j, len(html)):
        ch = html[k]
        if in_str:
            if esc:      esc = False
            elif ch == '\\': esc = True
            elif ch == '"':  in_str = False
            continue
        if ch == '"':  in_str = True
        elif ch == '{': depth += 1
        elif ch == '}':
            depth -= 1
            if depth == 0:
                try:
                    return normalize(json.loads(html[j:k+1]))
                except json.JSONDecodeError:
                    return None
    return None
```

### 短路熔断（重要优化）

私密 / 已删除的链接**不再重试**，直接 2 秒内返回。避免无谓等待。

```python
def is_terminal_state(detail: dict) -> bool:
    """判断是否为终态失败（私密/已删除/审核中）"""
    if not detail:
        return True
    if detail.get('status_code') != 0:
        return True
    if detail.get('video', {}).get('is_private') == 1:
        return True
    if not detail.get('video') and not detail.get('images'):
        return True
    return False
```

## 5. 第五步：视频 / 图集分支

### 视频分支

```python
def extract_video_urls(detail: dict, quality: str = '720p') -> str | None:
    """
    quality: '720p' | '1080p' | 'origin'
    """
    addrs = (detail.get('video', {}).get('play_addr', {}).get('url_list')
             or detail.get('video', {}).get('download_addr', {}).get('url_list'))
    if not addrs:
        return None
    url = addrs[0]

    # ⭐ 核心：去掉 playwm → play
    url = url.replace('/playwm/', '/play/')

    # 清晰度控制
    if quality == '720p':
        url = re.sub(r'ratio=\d+', 'ratio=720p', url)
    elif quality == '1080p':
        url = re.sub(r'ratio=\d+', 'ratio=1080p', url)

    return url
```

**`playwm` → `play` 就是去水印的关键** —— 同一个 CDN 上两个路径，一个带水印一个不带。

⚠️ **清晰度参数是主要成本控制点**：免费用户返 720p，会员返 1080p。**解析时即降级，不做下载后转码**（省 GPU）。

### 图集分支（你确认要做）⭐

```python
def extract_images(detail: dict) -> list[str]:
    """图集：返回全部图片地址（已去水印）"""
    images = detail.get('images') or []
    urls = []
    for img in images:
        ul = img.get('url_list') or []
        if not ul:
            continue
        # 图集同样有 playwm/play 之分
        u = ul[0].replace('/playwm/', '/play/')
        urls.append(u)
    return urls
```

**图集的关键差异：**

| 项 | 视频 | 图集 |
|---|---|---|
| 数量 | 1 个文件 | **N 张图片** |
| 带宽成本 | 单文件 | **× N** ⚠️ |
| 配额 | 每次 1 次 | ⚠️ **必须单独限次** |
| 保存方式 | `saveVideoToPhotosAlbum` | 逐张 `saveImageToPhotosAlbum` |

## 7. 解析器抽象（支持多平台）

```python
class BaseParser:
    domain: str = ''
    def match(self, url: str) -> bool:
        raise NotImplementedError
    async def parse(self, url: str) -> dict:
        raise NotImplementedError

class DouyinParser(BaseParser):
    domain = 'douyin.com'
    def match(self, url): return 'douyin.com' in url
    async def parse(self, url):
        aweme_id, ctype = extract_aweme_id(url)
        if not aweme_id:
            return await self._by_share_text(url)   # 回退到 share text
        return (await parse_level1(aweme_id)
                or await parse_level2(aweme_id)
                or await parse_level3(aweme_id)
                or {})
```

## 8. 其他平台的差异

| 平台 | 内容 ID 特征 | 解析方式 | 图集 |
|---|---|---|---|
| 抖音 | 纯数字 19 位 | 三级降级 | ✅ |
| 快手 | 短 ID 字母数字 | 移动端 UA 抓 SSR | ⚠️ 部分 |
| 小红书 | **24 位 base62** | SSR `__INITIAL_STATE__` | ✅ |
| B站 | `BV` 开头 | 官方 view 接口 | ❌ |

⚠️ **小红书 ID 不是数字**，且 SSR 用 `window.__INITIAL_STATE__`（双 UA 回退：App 链用移动 UA，PC 链用 PC UA）。

## 9. 图集的额外成本控制

⚠️ **图集是带宽成本的重灾区** —— 一次 9 张 = 视频的 9 倍成本。

| 控制项 | 建议 |
|---|---|
| 免费用户图集配额 | **单独限次**（如每月 2 次） |
| 免费图集返回 | **只返回 3 张预览** + 提示"开通会员看全部" |
| 会员 | 不限量 |
| 图集不提供"直连预览" | 图片必须在服务端中转（`saveImageToPhotosAlbum` 需 `downloadFile` 白名单） |

> 💡 **「免费只给 3 张预览」是很好的转化钩子** —— 用户看到一半被打断，付费意愿明显上升，且我们的带宽成本可控。
