> 验证时间：2026-10-04
> 测试链接：用户提供的真实分享口令（`v.douyin.com/ntaaK4aH9pE/`）
> 目标视频：ID `7692364828996128121`

## 0. 结论

| 项 | 结果 |
|---|---|
| **短链提取** | ✅ 通过 |
| **302 跳转拿 ID** | ✅ 通过，得到真实 ID |
| **L1 移动端 Feed 接口** | ❌ HTTP 200 但**返回空 body** |
| **L2 slidesinfo 接口** | ❌ `aweme_details: null` |
| **L3 移动端 SSR** | ❌ 页面返回「**抱歉出错了，请尝试在抖音内观看**」 |
| **真机浏览器（移动端 UA）** | ❌ 同样报「抱歉出错了」 |

### 🔴 核心判断

**2026 年 10 月，抖音已对非 App 内来源全面关闭解析通道。**

之前调研的 `ucmao/media-parser` 文档明确说过"403 率为 0%"，那是**当时的实测**。现在（2026-10）**这条通道已经关闭**。

⚠️ **这验证了我之前反复强调的那个风险是真的：**
> *"抖音会不定期更新水印算法，如果一款工具长期没有维护更新，很快就会失效。"*

**我们正好撞上了这个时间点。**

## 1. 详细诊断

### 第一步 ✅ 短链提取

```
输入：8.23 y@g.OX 05/26 ... https://v.douyin.com/ntaaK4aH9pE/ 复制此链接...
提取：https://v.douyin.com/ntaaK4aH9pE/
```

正则 `https?://[^\s，。、""'）)】\]]+` 有效，**正确排除了中文标点**。

### 第二步 ✅ 302 跳转

```
最终 URL：https://www.iesdouyin.com/share/video/7692364828996128121/?region=CN&mid=...
```

短链正常跳转到分享页，**拿到了真实存在的 aweme_id**。

> ⚠️ 这一步成功说明：**用户分享的链接本身是有效的**。

### 第三步 ❌ 三级解析全部失败

**L1 移动端 Feed 接口**
```
HTTP 200, body_len=0
```

**L2 slidesinfo**
```json
{"aweme_details": null, "status_code": 0, ...}
```

⚠️ 注意 `status_code: 0` 是**成功码**，说明接口没被墙、签名没问题，**但就是不返回数据**。

**L3 SSR 花括号栈**
```json
{
  "loaderData": {
    "video_layout": null,          ← 空
    "video_(id)/page": {
      "renderInSSR": 1,
      "serverToken": "",           ← 空
    }
  }
}
```

`serverToken` 为空 + `video_layout` 为 null = **抖音服务端明确决定不渲染这个视频**。

**真机浏览器（移动端 UA、完整分享 URL）**
```
抱歉出错了
请尝试在抖音内观看
```

## 2. 这意味着什么

### 🔴 纯解析路线（v2 方案）当前不可行

| 前提 | 状态 |
|---|---|
| 免签名通道可用 | ❌ **已关闭** |
| 免 Cookie 通道可用 | ❌ **已关闭** |
| SSR 兜底可用 | ❌ **已关闭** |

**整个 v2 方案的技术基础在今天已经不存在了。**

### 但还有路

| 路径 | 可行性 | 说明 |
|---|---|---|
| **A. 逆向签名（a_bogus / X-Bogus）** | 🟡 | X-Bogus 已死；a_bogus 需养一个逆向团队，**每周迭代** |
| **B. 代理 IP + Cookie 池** | 🟡 | 需真实用户 Cookie 池，风控严且有法律风险 |
| **C. 接入第三方解析 API** | 🟡 | 商业服务，有持续成本，且不稳定 |
| **D. 换方向** | ✅ | 见下 |

### ⚠️ 重新评估后剩下的选择

| 方向 | 说明 |
|---|---|
| **D1. 做"用户自有内容处理"工具** | 回到 v1 的 AI 净化路线（去自己加的水印/字幕），**不依赖平台接口** |
| **D2. 做合规的素材管理工具** | 不解析第三方平台，只做格式转换、压缩、封面制作等 |
| **D3. 等平台策略回退** | 不可控 |
