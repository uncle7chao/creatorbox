## 2. 🔴 关键发现：他们的「去水印」到底是什么

### 手册原文（完整操作流程）

> **一键去水印「一键解析视频」**
> 1. 点击「一键解析视频」。
> 2. 进入后，您可在此方框内**粘贴您想要去水印的视频链接**，目前支持**抖音、快手等几十家视频平台**链接。
> 3. 复制粘贴成功后，点击下方「**开始解析链接**」。

### 结论：这是「资源溯源」，不是「像素净化」

| 维度 | 魔音工坊 | CreatorBox |
|---|---|---|
| 原理 | **提取无水印原始资源直链** | AI 像素级 inpainting 修复 |
| 操作 | 粘贴链接 → 解析 → 下载 | 框选水印 → 端侧处理 |
| 适用范围 | **只对"平台原始文件就无水印"的场景有效** | 任意图片/视频的水印、字幕、logo |
| 处理本地文件 | ❌ 不能 | ✅ 核心能力 |
| 平台依赖 | 强依赖各平台接口存活 | 端侧处理，与平台无关 |
| 画质 | 原始画质 | 修复后画质 |

### ⚠️ 这个差异比想象中更大

**资源溯源型解析有三个致命弱点：**

1. **只能处理"平台原始文件无水印"的内容** —— 用户截图后加的水印、带其他 App 水印的图片、自己加的字幕，**完全无法处理**
2. **平台改版即失效** —— 抖音已经改过多次版
3. **X-Bogus 已死、a_bogus 每周迭代** —— 长期维护成本极高

**而魔音把这个功能放在「效率工具」里当引流，不是在做主业。**

**（历史价：VIP ¥24/月、SVIP ¥83/月，来自广发证券研报 → 说明他们在涨价）**

### 4.2 他们的会员运营设计（值得抄的三点）

| 设计 | 做法 | 我们怎么用 |
|---|---|---|
| **免费额度极高** | 80 次/天配音 | ⚠️ **我们原定"每日 3 次解析"太抠**，应放开 |

## 5. 对我们的三条战略修正

### 修正一：小程序首页定位必须改 ⭐ 最重要

既然解析是"几十家平台都支持"的成熟功能，我们再以"解析"为核心卖点 = 正面撞上市公司已有功能。

| | 现在（错） | 修正（对） |
|---|---|---|
| 标题 | 素材采集 | **素材净化** |
| 主文案 | 解析 · 采集 · 净化 | **去水印 · 去字幕 · 本地处理** |
| 主 CTA | 粘贴链接 | **选择图片/视频 → 框选水印** |
| 解析功能位置 | 核心 | 放在"工具"二级入口 |

**⚠️ 这会导致已设计的三张 UI 稿要重做主 CTA 和布局。**

### 修正二：免费额度放开

| | 原方案 | 修正 |
|---|---|---|
| 解析次数 | 每日 3 次 | **不限次**（解析成本极低，几个 HTTP 请求） |
| 保存到相册 | 每月 3 次 | **每月 3–5 次**（这才是带宽成本项） |

### 修正三：补上「按次/点数」付费层

```
免费（广告变现）
  ↓
9.9 元/月订阅（不限次数 + 1080p + 去广告）
  ↓
云端精修点数包（GPU 成本，按次消耗）← 补这一层
  ↓
商单变现（后期，参考他们的"我的商单"）
```

## 6. 我们真正的护城河（确认）

| 护城河 | 魔音有没有 | 为什么难被复制 |
|---|---|---|
| **端侧 AI 像素净化** | ❌ 没有 | 要做需要：LiteRT/CoreML 端侧推理 + 时序一致性算法 + 移动端调优，团队门槛高 |
| **素材不出设备的隐私承诺** | ❌ 没有 | 纯本地处理，审核无红线（微信最敏感的就是这个问题） |
| **广告免费模式** | ❌ 没有 | 他们的商业模式是会员订阅，必须收费才能活 |

**结论：护城河成立，但需要把"本地 AI 净化"做成第一卖点，而不是"解析"。**
