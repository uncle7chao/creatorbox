## 一、我们收集哪些信息

| 信息类型 | 具体内容 | 收集时机 | 存储位置 | 存储时长 |
|---|---|---|---|---|
| 微信标识 | `openid`（微信小程序唯一标识） | 首次调用解析功能时（`wx.login` 换取） | 服务端 SQLite `users` 表 | **长期保存**（账号存在期间） |
| 用户资料 | 昵称、头像 | **当前版本不收集**（小程序端未调用 `getUserProfile` / `getUserInfo`） | — | — |
| 设备标识 | App/PC 端安装时生成的随机 UUID | 跨端绑定时 | 服务端 `identities` 表 | **长期保存** |
| 登录凭证 | 跨端绑定 token | 绑定确认成功后 | 服务端 `auth_tokens` 表 | **90 天**，到期自动失效并删除 |
| 使用记录 | 解析次数、素材库条目（标题/平台/作者/链接） | 使用对应功能时 | 服务端 `quota_daily` / `library_items` 表 | 配额记录滚动保留；素材库条目**长期保存**，用户可自行删除 |
| **用户上传的文件** | PDF 文件（合并 / 提取 / 加水印） | 使用 PDF 工具时 | 服务端临时目录 `server/media/pdf/` | **1 天**（每 6 小时清理一次） |
| 绑定码 | 一次性 6 位数字 | 跨端绑定时 | 服务端 `bridge_codes` 表 | **5 分钟**或确认后立即删除 |

**我们不收集**：手机号、通讯录、精确位置、麦克风/摄像头、相册全量内容。

## 二、信息的使用目的

| 信息 | 用途 |
|---|---|
| `openid` | 账号唯一识别、每日配额统计、会员状态判定、素材库归属 |
| 设备 UUID | App/PC 端跨端绑定的身份锚点（同一账号在多端识别为同一用户） |
| token | App/PC 端登录态校验，90 天有效 |
| 解析记录 | 配额扣减（防止滥用）、素材库内容供用户本人回看 |
| PDF 文件 | 完成用户主动请求的文件处理，**处理完即焚**，不用于任何其他用途 |

**我们不会将上述信息用于以下目的**：
- 不用于广告定向投放
- 不出售、出租或以任何形式提供给第三方（除法律法规强制要求外）
- 不用于用户画像或机器学习训练

## 三、第三方 SDK 与共享

| 第三方 | 类型 | 收集的信息 | 场景 |
|---|---|---|---|
| 微信广告组件（`<ad>`） | 微信官方广告 | 由微信 SDK 按其规则处理，遵循微信隐私协议 | 展示广告时 |
| 各内容平台（抖音/B站/快手等） | 内容来源 | **不向平台传输任何用户个人信息**；仅在服务端发起公开内容请求 | 解析链接时 |

> 说明：解析请求由**我们的服务端**发起，用于获取平台公开展示的内容地址。
> 用户粘贴的链接会发送至平台以完成解析，此过程不包含用户身份标识。

## 四、用户的权利

| 权利 | 行使方式 |
|---|---|
| 查阅自己的数据 | 会员页 / 素材库页可查看已保存的解析记录与文案 |
| 删除单条记录 | 素材库页每条右侧菜单 →「删除」 |
| 删除 PDF 文件 | 处理完成 1 天后自动删除；如需提前删除可联系客服 |
| **注销账号** | **已支持自助**：预览将删除的数据 → 二次确认后立即删除全部个人数据（openid、素材库、配额、跨端身份、登录凭证、未确认的绑定码） |
| 撤回授权 | 在微信「设置 → 小程序 → 授权管理」中撤回；撤回后将无法使用需登录的功能 |

### 注销的技术说明

- 注销入口：`GET /api/auth/purge/preview`（预览影响范围）→ `POST /api/auth/purge`（确认注销）
- **两道防误触闸**：① 必须携带有效 token（拿不到 user_id，陌生人无法注销他人账号）
  ② 确认请求须回传 user_id，前端需在弹窗中明示「不可恢复」
- 注销**不可逆**，且会同步使该账号在小程序与 App/PC 端的全部登录态失效
- **不随账号删除的运营数据**：卡密库、违禁词库、平台订单、健康探针记录（属运营资产，非用户数据）

## 五、数据存储与安全

- **存储地点**：数据存储于中华人民共和国境内（中国大陆服务器）
- **传输加密**：线上环境全站 HTTPS
- **访问控制**：账号数据仅在解析、配额、素材库功能所必需范围内读写
- **安全措施**：
  - 数据库不直接对外暴露，仅通过服务端接口访问
  - 跨端 token 采用不可预测的随机串，有效期 90 天且到期即焚
  - 一次性绑定码 5 分钟失效，并有防爆破锁定（5 次失败即作废）
  - Cookie 等凭据类配置不纳入版本管理（见 `.gitignore`）
