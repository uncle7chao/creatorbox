# CreatorBox 橙金配色系统

> v2 · 2026-10-06 用户拍板：主色从深绿 `#173404` 换成橙金
> **目的**：与 GEO Optimizer 品牌调性统一
> 原规范 `小程序UI设计规范.md` 里的深绿版**保留不改**（历史决策留档），
> 本文件是**生效版本**，两处冲突时以本文件为准。

---

## 零、为什么换

| 项 | 说明 |
|---|---|
| 品牌 | CreatorBox 与 GEO Optimizer 属同一工作室（哎呀码呀），橙金是工作室主色 |
| 感知 | 暖色比深绿更亲和，适合「创作者工具」而非「技术工具」 |
| 转化 | 橙金在白底上对比度更高，按钮更「可点」 |
| 保留 | 深绿的「无水印」信任徽章语义 → 改成**青绿**，继续承担"可靠"的视觉表达 |

⚠️ 关键约束：**主色换了，但「成功/可信」的语义色不能跟着变暖**。
水印去除成功徽章若用橙金，会与主 CTA 撞色、失去区分度 → 保持冷绿。

## 二、深色区渐变（替代原 `#173404` 实色）

原方案用**实色深绿**，橙金改渐变更耐看（纯橙金大面积会刺眼）：

```css
background: linear-gradient(160deg, #3D2000 0%, #5C3200 55%, #8A4B00 100%);
```

⚠️ 橙金必须用**深棕→橙**的渐变，不能用纯橙。
纯橙 `#E8890C` 当大面积底会晃眼且文字对比度不足。

## 四、无障碍对比度（WCAG）

| 前景 | 背景 | 对比度 | 等级 |
|---|---|---|---|
| `#1A1614` 主文字 | `#FFFFFF` | 15.2:1 | ✅ AAA |
| `#FFFFFF` | `#E8890C` 主 CTA | 2.6:1 | ⚠️ **仅大字号/图形可用** |
| `#1A1614` | `#E8890C` 主 CTA | 8.1:1 | ✅ AAA（文字用这个） |
| `#FFFFFF` | `#1B8A5A` 成功徽章 | 4.2:1 | ✅ AA（≥4.5 需大字号） |
| `#FFC46B` | `#3D2000` | 8.9:1 | ✅ AAA（深色区次级文字）|
| `#7D736B` 辅助 | `#FAF7F4` | 4.6:1 | ✅ AA |
| `#C77700` | `#FFF4E0` | 4.1:1 | ⚠️ 大字号/图形 |

⚠️ **主 CTA 的文字必须是 `#1A1614`（深色），不能白色** ——
白字在橙金上只有 2.6:1，不达 AA。这是换橙金后**最容易踩的坑**。

## 五、实现落地

### 小程序（WXSS）
```css
page{ background:#FAF7F4; }
.hero{ background:linear-gradient(160deg,#3D2000,#5C3200 55%,#8A4B00); }
.cta{ background:#E8890C; color:#1A1614; }        /* ⭐ 深色字*/
.badge-nwm{ background:#1B8A5A; color:#fff; }
.warn-bar{ background:#FFF4E0; border-left:3px solid #C77700; color:#8A4B00; }
```

## 六、换色后的连带检查（易漏）

| 位置 | 说明 |
|---|---|
| 「全部已验证」徽章 | 原本可能是绿系→ 改成 `success500` 冷绿，别用主色 |
| 进度条 / 加载态 | 用 `brand500` |
| 骨架屏 shimmer | 高光用 `brand100`，底色 `bgSunken` |
| 图表主色序列 | `[brand500, brand300, success500, info500]` |
| 水印框选标记 | ⚠️ **必须用高对比红 `#FF3B30`**，不能用主色 ——用户要精确框水印位置，暖色会与内容混 |
| 删除/清空按钮 | `danger500`，不用灰（灰=禁用）|
| 会员/付费强调 | 仍是 `brand500`，与主 CTA 同色但位置不同 |

## 七、A/B 建议（上线后测）

橙金 vs 深绿在**转化率**上谁更高，现有资料无法判断，取决于：
- 目标用户（专业创作者 vs 泛用户）
- 投放素材（是否用暖色系封面）

上线后建议 A/B：深绿版保留 feature flag，一键切换。
**不要凭喜好定转化率** —— 用埋点数据说话。
