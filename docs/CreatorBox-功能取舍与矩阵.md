# CreatorBox 功能取舍评估（对标魔音工坊工具矩阵）

> 版本 v1.0 ｜ 2026-10-04
> 背景：竞品已有一键去水印（资源溯源型），我们需要差异化 + 功能组合撑起订阅

---

## 0. 结论先行

**建议纳入 5 个功能，形成「采集 → 净化 → 检测」三段闭环。**

但**不是简单照搬** —— 魔音的工具矩阵是围绕 TTS 音频的，每个工具都服务于"把文案变成配音视频"这条主线。我们没有配音，所以要换成另一条主线：

> **「素材从哪来 → 怎么变干净 → 怎么证明它干净」**

⚠️ **绝对不能碰的两个**（会直接致死）：真人配音、赚钱商单 —— 详见 §4。

## 2. 🔴 两个绝对不能碰的（会直接致死）

### 2.1 真人配音 —— 法律红线

- 需配音演员**逐字授权书 + 肖像权/声音权授权**，录音棚录制，一整套法律流程
- 需处理「声音被 AI 克隆后用于伪造」的风险
- 周期 6 个月+，需要法务预算
- **我们没有配音业务，这钱花得毫无价值**

### 2.2 赚钱商单 —— 会让广告收入崩盘

⚠️ **这条最反直觉，必须解释清楚：**

我们靠**广告变现**。而"赚钱商单"会引入**带货、推广、返佣内容**——这些是**广告主和平台的直接竞争对手**。

| 后果 | 说明 |
|---|---|
| 微信审核风险 | 微信明确禁止**诱导分享/诱导添加**，商单导流极易触碰 |
| 广告主抵触 | 我们的用户看到"带货返佣"内容后，广告投放意愿下降 |
| 用户质量下滑 | 白嫖用户里大量薅羊毛的，不是真实创作者 |
| 主线偏移 | 从"工具"变成"内容平台"，需要审核团队 |

**我们的定位是「素材工具」，不是「创作者变现平台」。** 一旦做商单，性质就变了。

## 3. 建议纳入的 5 个功能（按优先级）

### 🔴 P0 · 核心（App 端，M2–M3）

| 功能 | 端 | 差异化优势 |
|---|---|---|
| **图片去水印/去字幕** | App | 🔴 魔音完全没有（他们只能解析） |
| **视频去水印/去字幕** | App | 🔴 魔音完全没有 |
| **元数据净化**（C2PA/EXIF/零宽字符） | App + 小程序 | 🔴 魔音完全没有 |

**这三个是我们真正的护城河**，且都是端侧处理（零服务器流量）。

### 🟢 P1 · 增值（成本低、价值高，用来撑订阅）

| 功能 | 端 | 为什么值得做 |
|---|---|---|
| **自动打轴** | 小程序 + App | 🎯 纯文本时间轴对齐，**技术极简单**，但创作者强需求（配音+字幕工作流的刚需） |
| **封面制作** | 小程序 + App | 🎯 模板拼图，**开发量小**，且是发视频的必需品（抖音封面） |
| **清晰度转换** | 双端 | 补充变体（1080p↔720p 码率调整），带宽成本可控 |

> ⭐ **这两个是"撑订阅"的甜头**：开发量小、用户感知强、可以放进 9.9 会员权益里当赠品。

### 🟡 P2 · 补充（M4 之后，看数据再决定）

| 功能 | 端 | 评估 |
|---|---|---|
| **文案提取**（ASR 端侧） | App | 🟢 端侧 Whisper tiny 可行，隐私好；但和净化主线弱相关，**先观察** |
| **背景音/人声分离** | App | 🟡 魔音有，我们没有；但需要音频模型，工作量不小 |
| **一键成片** | 双端 | 🟡 图文转视频，抖音图文很火，值得观察 |

## 4. 完整功能矩阵（修订版）

```
CreatorBox

├─ 📥 采集（免费，拉新入口）
│  └─ 链接解析（降级为工具，不做核心）
│
├─ 🧹 净化（核心，App 端）⭐ 护城河
│  ├─ 图片去水印 / 去字幕        P0
│  ├─ 视频去水印 / 去字幕        P0
│  └─ 元数据净化（C2PA/EXIF）    P0
│
├─ ✂️ 创作辅助（P1，撑订阅）🎯
│  ├─ 自动打轴                   P1
│  ├─ 封面制作                   P1
│  └─ 清晰度转换                 P1
│
├─ 🔍 检测（合规护城河）
│  └─ AI 内容检测与举证          P0（只做检测，不做去除）
│
└─ ⚙️ 我的
   ├─ 素材库（跨设备同步）
   ├─ 会员 9.9
   └─ 举报 / 投诉 / 反馈
```

**三层价值：**
- **采集** —— 白嫖用户从这里进来（免费不限次）
- **净化** —— 订阅的核心价值（App 端专属，素材不出设备）
- **创作辅助** —— 免费送一部分，订阅送全部（撑起 9.9 的"值"的感觉）

## 5. 会员 9.9 权益（修订）

| 权益 | 免费 | 9.9 订阅 |
|---|---|---|
| **链接解析** | ✅ 不限次 | ✅ 不限次 |
| **图片去水印** | 每日 3 次 | **不限** |
| **视频去字幕** | ❌ | ✅ 不限（1080p） |
| **元数据净化** | 每日 3 次 | **不限** |
| **自动打轴** | 试用 1 次 | ✅ |
| **封面制作** | 带水印 | ✅ 无水印 + 模板库 |
| **清晰度** | 720p | 1080p / 原画 |
| **AI 内容检测** | 每日 1 次 | ✅ 完整报告 |
| 广告 | 有 | ✅ 去广告 |
| 素材库 | 500MB | 5GB |

> 💡 **免费额度设计原则（修正）**：解析不限次（成本极低）、去水印限次（成本可控）、AI 检测 1 次（引导体验）。

## 6. 与魔音的最终定位对比

| | 魔音工坊 | CreatorBox |
|---|---|---|
| **一句话** | AI 配音 + 声音商店 | **素材净化 + 创作辅助** |
| 主线 | 文案 → 配音 → 视频 | 素材 → 净化 → 发布 |
| 核心资产 | 1000+ 声音、签约配音演员 | **端侧 AI 净化能力** |
| 商业模式 | 订阅 + 声音付费 + 点数包 | 广告 + 订阅 + 点数包 |
| 免费额度 | 80 次/天配音 | 解析不限次 + 去水印限次 |
| 处理本地文件 | ❌ 不能 | ✅ 核心能力 |
| 隐私 | 云端处理 | **端侧处理，素材不出设备** |

**错位清晰，不冲突。**

## 7. 建议的排期调整

| 阶段 | 原来 | 修订后 |
|---|---|---|
| M2 | App 图片 | App 图片去水印 + 元数据净化 |
| M3 | App 视频 | App 视频去字幕 + **自动打轴 + 封面制作**（提前到 M3，撑订阅） |
| M4 | 商业化 | 商业化 + **AI 内容检测** |
| M5（新增） | — | 文案提取 / 背景音分离（看数据决定） |

⚠️ **自动打轴 + 封面制作建议提前到 M3**：它们是 9.9 订阅的"赠品"，没有它们，9.9 卖相单薄（只有一个"去水印"值 9.9，用户会犹豫）。
