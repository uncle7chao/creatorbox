## 一、先说结论：要不要买服务器？

**要。** 而且这是整条链路上**最该立刻做**的事。

原因不是流量主（那是变现的事），是 **ICP 备案本身必须有大陆服务器作为载体**——
你在云服务商提交备案，前提是名下有一台大陆的云产品。香港那台（43.159.141.17）**办不了备案**。

| | 现状 | 谁做 | 耗时 | 卡住的后果 |
|---|---|---|---|---|
| 小程序备案 | 平台审核中 ✅ | 你 | 1~3 周 | — |
| **① 买国内轻量服务器** | **待办** | **你** | **当天** | **备案无法提交** |
| ② 域名 ICP 备案 | 待办 | 你 | 15~20 工作日 | **不能上线** |
| ③ 部署服务 | 待办 | 我+你 | 30 分钟 | — |
| ④ 配合法域名 | 待办 | 你 | 10 分钟 | **真机全白屏** |
| ⑤ 提审发布 | 待办 | 你 | 1~3 天 | — |

**①②是长周期，③⑤是分钟级。把时间花在①上。**

## 二、① 买服务器（今天就做）

**配置**：腾讯云轻量应用服务器 / 阿里云轻量，**2 核 2G** 就够
（国内 8 平台解析 + 全部业务；香港那台同档）

**地域**：北京/上海/广州任一（**必须在大陆**，选离用户近的）

**系统**：Ubuntu 22.04 LTS（脚本按这个写的）

**镜像里勾**：不要预装宝塔也行，但装了更省事（下面步骤按「宝塔 + 纯 systemd」都能走）

**为什么不能省**：这是备案的载体，且要跑解析服务。2C2G 是实测够用的档位
（服务端串行解析 + SQLite + 8 平台，内存占用 < 500MB）。

## 三、② 域名 ICP 备案（买完服务器当天提交）

**前提**：域名已实名认证。域名在哪注册都行，但**备案要在服务器所属的云服务商提交**。

**入口**：腾讯云 → 控制台 → 备案管理 / 阿里云 → ICP 备案

**要注意的**：
- 主体信息要和**小程序的主体一致**（个人 vs 企业必须统一，否则域名过了小程序那关会卡）
- 网站名称：建议用「星创映画」或与小程序名一致
- 服务内容按「工具类」填，别选需要资质的类目
- 备案期间**网站不能对外提供服务**（会查到），这是正常的，别慌
- 备案期间可以做开发联调（用香港机或本机）

**拿到备案号后**（形如 `粤ICP备xxxx号-x`），这个号需要挂在小程序页脚。

## 四、③ 部署服务（备案通过后 30 分钟）

### 4.1 本机打包

```powershell
cd D:\WorkBuddyFILE\CreatorBox
powershell -ExecutionPolicy Bypass -File deploy\pack.ps1
```

产物：`deploy\creatorbox_server_<日期>.zip`

### 4.2 上传到服务器

宝塔文件管理上传，或 scp：

```powershell
scp D:\WorkBuddyFILE\CreatorBox\deploy\creatorbox_server_*.zip root@<你的服务器IP>:/www/creatorbox/
```

### 4.3 服务器端安装

```bash
mkdir -p /www/creatorbox && cd /www/creatorbox
unzip -o creatorbox_server_*.zip -d server
cd server && bash ../deploy/install.sh
```

脚本会自动做完：venv → 依赖 → chromium → 数据目录权限 → env 文件 → systemd 单元。

### 4.4 填密钥

```bash
sudo nano /etc/creatorbox/env
```

**至少要填这三项**：

```
CB_API_KEY=<用 python3 -c "import secrets;print(secrets.token_urlsafe(32))" 生成>
CB_WX_APPID=wx你的小程序AppID
CB_WX_SECRET=你的小程序AppSecret
```

### 4.5 启动 + 验证

```bash
sudo systemctl enable --now creatorbox
systemctl status creatorbox
bash ../deploy/verify-cn.sh
```

**verify-cn.sh 会逐条告诉你哪一项坏了** —— 不用在白屏里猜。
常见三种：
- 管理接口 503 → CB_API_KEY 没填
- 解析接口 4xx/5xx → `journalctl -u creatorbox -n 50`
- 数据库 readonly → `chown -R www:www /www/creatorbox/server/data`

### 4.6 Nginx + HTTPS

宝塔面板 → 网站 → 添加站点（填你的域名）→ 反向代理到 `http://127.0.0.1:8080`
→ SSL → Let's Encrypt → **Full 模式**（不要 Flexible）

防火墙只开 80/443，**8080 不对公网**。

### 4.7 验证外网可达

```bash
curl -s https://<你的域名>/api/health | head -c 200
```

## 五、④ 配置小程序合法域名（最容易翻车的一步）

**后台路径**：小程序后台 → 开发 → 开发设置 → 服务器域名

**要配三类**（不同类型不能互相替代）：

| 类型 | 用途 | 你要填 |
|---|---|---|
| request 合法域名 | API 调用 | `https://<你的域名>` |
| uploadFile 合法域名 | PDF 工具上传 | `https://<你的域名>` |
| downloadFile 合法域名 | 图片/视频/音频下载 | `https://<你的域名>` |

**硬性规则**（踩了就是白屏）：
- 只能 `https`（`wss` 用于 WebSocket，本项目暂未用）
- **不能用 IP、不能用 localhost**
- 每个域名**最多 1 个端口**；不配端口时请求 URL 里**也不能带端口**（含默认 443）
  → 所以请求地址必须写成 `https://api.xxx.com/api/parse`，不能是 `https://api.xxx.com:443/api/parse`
- **不支持父域名**，用子域名要单独配 + 单独备案

### 改小程序里的服务地址

```powershell
# 编辑 miniapp\config\env.js，把 BASE_URL 改成你的域名
const BASE_URL = 'https://<你的域名>';
```

**开发期**（开发者工具）：详情 → 本地设置 → 勾「不校验合法域名」
**验证期**：配置完域名后**把这个勾去掉**再测一遍——勾着能通不代表配对了。

### ⭐ 漏改的后果

`BASE_URL` 如果还指着 `http://127.0.0.1:8080`：
- 开发者工具（勾了不校验）→ 正常
- **真机预览 → 全挂**（127.0.0.1 在手机上指手机自己）
- **正式版 → 全挂**（微信强制校验合法域名）

所以改完 BASE_URL 一定要**真机预览**一次再提审。

## 六、⑤ 提审发布

1. 微信开发者工具 → 上传（版本号 + 版本描述）
2. 小程序后台 → 版本管理 → 提交审核
3. 类目选「工具」
4. 隐私保护指引：项目里已写好 `docs/小程序隐私保护指引.md`，照着填
   （含账号注销入口 —— 审核会点，缺了直接驳回）
5. 审核通过 → 发布

**审核常见驳回点自查**：
- 找不到「删除账号/注销」入口 → 驳回（会员页已做）
- 服务类目与实际功能不符 → 驳回
- 隐私指引声明与实际收集的信息不一致 → 驳回

## 七、并行：现在就能做的开发

备案和服务器不阻塞这些事：

- **App/PC 端编译验证**：`flutter pub get && flutter build windows --debug`
- **提审收敛开关**：需要时把服务端的 `CB_REVIEW_MODE` 设为 `review`
  （只保留抖音+B站入口，隐藏其他平台；注意**收敛≠停用**，粘贴链接仍可解析）
- **香港机做联调**：把 `CB_REVIEW_MODE=full` 跑在 43.159.141.17 上，
  小程序开发版连它（需 HTTPS + 合法域名，域名仍要已备案）
